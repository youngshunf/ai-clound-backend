# finance App — 工具说明（TOOLS.md）

> AI-Native App `finance`（金融数据源 akshare 行情与投研，HExt-08）面向 Agent 的 Tool API 规格说明。
> **运行时权威源是 DB JSONB manifest**（builtin seed 见
> `backend/app/hasn_finance/manifest.py` 的 `FINANCE_AI_NATIVE_MANIFEST`）。本文件是人类可读规格，
> **必须与 manifest 一致**（由 `tests/mcp/test_app_tools_doc_consistency.py` 校验，零漂移）。

> 形态：纯云端**只读数据**应用。工具一律走云端 MCP（`transport=gateway_internal`，handler 落
> `backend/app/hasn_finance/service/finance_tool_handlers.py`）→ `finance_provider`（httpx）→
> 独立部署的 **finance-data-service**（唯一接触 akshare 的地方，重依赖隔离在独立服务）。
> 主云端进程**不引 akshare**；Agent / WebUI **不直连**数据服务，一律经主云端中转。
> 数据服务自带：缓存（Redis 分层 TTL）+ 历史增量持久化（SQLite）+ 行截断（每次最多 300 行）+
> 上游错误归一（业务失败也回 ok:false，零 fake，绝不透 traceback）。

- scope 词表统一 `domain:action`（冒号，见 13-doc §3.3 / P1）：**单 scope `finance:read`**——14 工具全只读，
  无下单 / 无真钱 / 无写类 / 无审批。出厂 `risk=low`、`human_confirmation.required=False`（出厂全 Allow，D-v3-1）。
- 维度① 能力授权（allow/ask/deny）统一适用本 App 工具；只读类默认 `allow`，主人可设 ask/deny override。
- 维度②（企业角色裁剪）：**不适用**——金融行情是公共数据，不分主人 / 不脱敏 / 无 per-owner 状态，
  handler 的 `db`/`agent` 形参仅为契约一致而保留。
- **零 fake 与免责**：取数失败（上游超时 / 不可达 / 服务未配置）一律回诚实 `ok:false` 信封，绝不伪造数据；
  所有行情数据**仅供参考，不构成投资建议**。
