# finance App — 工具说明

> AI-Native App `finance` 已换根为 hasn-node 本地 Vibe-Trading 引擎。本文件只描述云端
> manifest 的工具面，必须与 `backend/app/hasn_finance/manifest.py` 一致。

## 当前执行形态

- `execution_mode=local_tool`、`transport_mode=local`。
- 云端 manifest 的 `capabilities[]` 与 `tools[]` 均为空，不再向 Agent 暴露旧 14 个
  `gateway_internal` 工具。
- 最终 44 个 `hasn.finance.*` 工具由 hasn-node 本地 MCP 注册并执行：38 个引擎工具与
  6 个平台工具。精确名称的事实源是 hasn-node `crates/hasn-mcp/src/finance.rs` 与 Hub
  `finance-playbook`。
- 旧云端只读 handler 在 F8 退役前只服务存量客户端，不属于新工具发现面，禁止作为 fallback。

## 平台契约

- 六类产物资源描述符、严格 `:sync` 与 register-on-write 仍由云端承接。
- `project_aware=true`、`project_required=false`：支持可选项目归集；不选项目时 finance
  仍可完整使用，不创建占位项目。
- 研究数据必须标注来源与时点；历史表现不代表未来，所有结果仅供研究参考，不构成投资建议。
- 引擎、数据源、云端或同步失败必须返回明确错误，禁止 mock、fake 或假成功。
