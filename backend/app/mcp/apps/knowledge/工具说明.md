# knowledge App — 工具说明（TOOLS.md）

> AI-Native App `knowledge`（HExt-08）面向 Agent 的 Tool API 规格说明。
> **运行时权威源是 DB JSONB manifest**（builtin seed 见
> `backend/app/hasn_knowledge/manifest.py` 的 `KNOWLEDGE_AI_NATIVE_MANIFEST`，
> 经 `backend/app/hasn/service/ai_native_builtin_manifests.py` 兼容导出）。本文件是人类可读规格，
> **必须与 manifest 一致**（由 `tests/mcp/test_app_tools_doc_consistency.py` 校验，零漂移）。

| 工具 (mcp_name) | required_scopes | risk | 用途 |
|---|---|---|---|
| `hasn.knowledge.search` | `knowledge:read` | low | 检索主人可见知识库的资料（命中片段 + 来源） |
| `hasn.knowledge.list_datasets` | `knowledge:read` | low | 列出分身可达的知识库（含文档数/分块数） |
| `hasn.knowledge.create_kb` | `knowledge:write` | medium | 替主人新建知识库（库归主人所有，返回 kb_id） |
| `hasn.knowledge.update_kb` | `knowledge:write` | medium | 改既有库的库名/描述/封面（如建库后补封面），按 kb_id manager 档判权 |
| `hasn.knowledge.delete_kb` | `knowledge:write` | high | 删除主人整个知识库（级联删全部文档/目录，不可恢复） |
| `hasn.knowledge.fetch_doc` | `knowledge:read` | low | 读取文档解析后的完整文本（native 正文 / file 分块文本）。检索片段自带 document_id/uri，靠它 fetch 全文 |
| `hasn.knowledge.list_documents` | `knowledge:read` | low | 列某知识库的文档（folder_id 省略=全库 / 0=库根 / >0=指定目录） |
| `hasn.knowledge.upload_document` | `knowledge:upload` | medium | **原生优先**：content_text→可编辑 native 文档（≤5000 字，超限拒，须拆分+深链）；asset_uri→真实二进制 file 文档并索引 |
| `hasn.knowledge.delete_document` | `knowledge:write` | medium | 删除知识库中的一篇文档（含索引副本，不可恢复） |
| `hasn.knowledge.write_doc` | `knowledge:write` | medium | 创建/更新可编辑原生文档（Markdown，≤5000 字，保存即重建索引；正文深链保存时强校验，跨库/失效即拒） |
| `hasn.knowledge.check_links` | `knowledge:read` | low | 写前预检正文里的文档深链 `hasn://knowledge/documents/{doc_id}` 是否合法（传 kb_id 或 doc_id 定位库；只校验、不落库） |
| `hasn.knowledge.move_document` | `knowledge:write` | low | 把已存在文档移进目录(folder_id)或移回库根(move_to_root)，只改归属不重索引 |
| `hasn.knowledge.list_folders` | `knowledge:read` | low | 列某知识库的目录树（平铺，按 parent_id 组树） |
| `hasn.knowledge.create_folder` | `knowledge:write` | low | 在知识库里新建目录（可指定父目录） |
| `hasn.knowledge.update_folder` | `knowledge:write` | low | 重命名目录 / 移动到另一父目录或库根 |
| `hasn.knowledge.delete_folder` | `knowledge:write` | low | 删除空目录（非空如实拒，不级联） |

- scope 词表统一 `domain:action`（冒号，见 13-doc §3.3 / P1）。
- 维度① 能力授权（allow/ask/deny）统一适用本 App 工具；默认 `allow`。
- 维度② 知识库白名单（inherit/restricted/denied）由主人授权；分身只见/只写可达库，够不到如实拒。
- 文件上传：`upload_document` 的 `asset_uri`（`hasn://asset/...`）须为同一主人名下资产，越权如实拒（D10）。
- **原生优先原则**：知识库以可编辑的 native 文档为主，能不落 file 就不落 file（native 可随时改，file 编辑成本高）。文本内容一律走 `content_text`（→ native）；只有真实二进制文件（PDF/docx/图片等）才用 `asset_uri`（→ file）。
- **单篇 native 上限 5000 字**（按 `len()` 计，中文 1 字 = 1）：超限直接拒（不截断、不自动降级为 file）。长内容须**拆成多篇 native 文档**，用文档深链 `[标题](hasn://knowledge/documents/{目标doc_id})` 互相跳转组织。
- **深链保存时强校验**：`write_doc`/`upload_document` 保存正文里的深链时，逐条校验目标文档存在且属**同一知识库**；指向已删/不存在/跨库文档即整篇拒。写前可用 `check_links` 预检（传 kb_id 新建前 / doc_id 更新前 + content），预检 valid 即保存不会因深链被拒。
- **省 token 取全文**：`search` 命中片段自带 `document_id` + `document_uri`（`hasn://knowledge/documents/{id}`）；片段不足以作答时，据此调 `fetch_doc` 拉全文，不必反复检索。
