# creator App — 工具说明（TOOLS.md）

> AI-Native App `creator`（自媒体创作运营，HExt-08）面向 Agent 的 Tool API 规格说明。
> **运行时权威源是 DB JSONB manifest**（builtin seed 见
> `backend/app/hasn_creator/manifest.py` 的 `CREATOR_AI_NATIVE_MANIFEST`）。本文件是人类可读规格，
> **必须与 manifest 一致**（由 `tests/mcp/test_app_tools_doc_consistency.py` 校验，零漂移）。

> 形态：纯云端业务应用，工具一律走云端 MCP（`transport=gateway_internal`，handler 落
> `backend/app/hasn_creator/service/creator_tool_handlers.py` → creator service），不经本地
> hasn-mcp / daemon Agent 代理。媒体生成（配图/封面）复用平台级 `hasn.image.generate`、口播配音复用
> `hasn.voice.synthesize`、素材落桶复用 `hasn.asset.upload`，不在本应用重造。

- scope 词表统一 `domain:action`（冒号，见 13-doc §3.3 / P1）：`creator:read`（读）/ `creator:manage`（写创作对象）/ `creator:publish`（请求发布，可被主人单独关死）。
- 维度① 能力授权（allow/ask/deny）统一适用本 App 工具；写/发布类默认 `allow`（出厂全 Allow，D-v3-1），主人可设 ask/deny override。
- 维度②（企业角色裁剪）：企业模式下「主编」（owner/admin）见全部、「运营」（member）只见 assignee=自己 的项目及其子对象；个人模式按 user_id 隔离。裁剪真相在后端 `CreatorScope`。
- `publish.submit` 的「过主人审核」是**业务态**（落 `pending_review`，§3.3），不走 ask_gate；工具如实回报状态，零 fake。method 默认 `manual_assist`（人工辅助发布为主）。
