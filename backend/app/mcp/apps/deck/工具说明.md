# deck App — 工具说明（TOOLS.md）

> AI-Native App `deck`（自研演示文稿，模块 17）面向 Agent 的 Tool API 规格说明。
> **运行时权威源是 DB JSONB manifest**（`hasn_ai_native_app_manifest.manifest_json`，
> builtin seed 见 `backend/app/deck/manifest.py` 的 `DECK_AI_NATIVE_MANIFEST`）。
> 本文件是人类可读规格，**必须与 manifest 一致**（由
> `tests/mcp/test_app_tools_doc_consistency.py` 校验，零漂移）。

> 落地真相以 hasn-node `crates/hasn-mcp/src/deck.rs`（写类 8 / 读类 4）为准；
> 设计见 `docs/hasn-node设计文档/17-演示文稿系统/07-安全权限与平台接入.md`。

| 工具 (mcp_name) | required_scopes | risk | 用途 |
|---|---|---|---|
| `hasn.deck.create` | `deck:manage` | medium | 新建空演示文稿（可带 title/topic/language/style）。返回 deck_id。 |
| `hasn.deck.get` |  | low | 取 deck 详情（outline / design_contract + 各页摘要）。**页正文默认不返回**，`include_html=true` 才回完整 HTML。 |
| `hasn.deck.list` |  | low | 列出当前 owner 的全部 deck（不含已删）。 |
| `hasn.deck.outline.set` | `deck:manage` | medium | 写 / 改 deck 大纲（OutlineItem[]）+ 可选 design_contract。 |
| `hasn.deck.page.write_batch` | `deck:manage` | medium | 批量写多页 HTML（主力，粗粒度）。逐页骨架校验；不合格页进 rejected 重写。 |
| `hasn.deck.page.write` | `deck:manage` | medium | 写单页 HTML（按 position 序数 upsert，幂等）。骨架不合格则进 rejected。 |
| `hasn.deck.page.edit` | `deck:manage` | medium | 编辑某页（按 page_id 局部更新；仅传需要改的字段）。 |
| `hasn.deck.page.delete` | `deck:manage` | high | 删除某页（删后自动重排剩余页序）。 |
| `hasn.deck.page.reorder` | `deck:manage` | medium | 重排页序：给定按目标顺序排列的全部页 id。 |
| `hasn.deck.finalize` | `deck:manage` | medium | 写完最后一页后调一次，标记 deck 已完成（draft/generating→ready）。首次收尾系统自动给主人发「演示文稿做好了」卡片（分身不用也不该自己发卡）；幂等，重复调不重复发卡。 |
| `hasn.deck.delete` | `deck:manage` | high | 删除演示文稿（软删，可同步撤销）。 |
| `hasn.deck.style.list` |  | low | 列可复用样式（内置 + 本 owner 自定义 StyleProfile），只回 slug/label/description/source。 |
| `hasn.deck.style.get` |  | low | 取单个样式（StyleProfile）：含 design_contract + style_prompt。 |

- **返回体一律不回显分身刚传的正文**（写工具只回 `id/position/title/status/rev/html_length` 摘要，
  `page.write`/`write_batch` 只回本次写入那几页 + `total_pages`）。返回体直接进分身上下文并按 token
  计费，把它刚传的 HTML 原样退回是纯浪费——实测单页均 2283 字符、最大的 deck 27 页共 7 万字符。
  要读回正文走 `get` 并显式 `include_html=true`；service 层 `_page_dict`/`_deck_dict` 未变，REST 面照旧。
- scope 词表统一 `domain:action`（冒号）。deck 仅一个写类能力键 `deck:manage`（早期占位
  `deck:read`/`deck:write` 已删，避免假闸门）；读类工具不声明 `required_scopes`。
- 维度① 能力授权（allow/ask/deny）统一适用本 App 工具；**出厂全 `allow`**（16-doc D-v3-1），
  owner 可经 `capability_modes` 把 `deck:manage` 设 ask/deny override。
- `risk` 仅 UI 风险提示（D4），不强制确认；`page.delete`/`delete` 标 high 仅作展示分级。
