# publish App — 工具说明（TOOLS.md）

> AI-Native App `publish`（通用网页发布与分享，模块 18）面向 Agent 的 Tool API 规格说明。
> **运行时权威源是 DB JSONB manifest**（`hasn_ai_native_app_manifest.manifest_json`，
> builtin seed 见 `backend/app/publish/manifest.py` 的 `PUBLISH_AI_NATIVE_MANIFEST`）。
> 本文件是人类可读规格，**必须与 manifest 一致**（由
> `tests/mcp/test_app_tools_doc_consistency.py` 校验，零漂移）。

> 落地真相以 hasn-node `crates/hasn-mcp/src/publish.rs`（写类 5 / 读类 2）为准；
> 设计见 `docs/hasn-node设计文档/18-通用网页发布与分享/`。

| 工具 (mcp_name) | required_scopes | risk | 用途 |
|---|---|---|---|
| `hasn.publish.create` | `publish:write` | medium | 发布一个自包含网页（html/path/source_ref 三选一）。返回 site_id + 分享 URL。 |
| `hasn.publish.update` | `publish:write` | medium | 更新站点内容（发新 revision，指向新制品）。可见性不变。 |
| `hasn.publish.set_visibility` | `publish:write` | medium | 改站点可见性（含口令）。升级到敏感可见性触发主人审批（无视「总是允许」的硬闸）。 |
| `hasn.publish.revoke` | `publish:write` | medium | 撤回发布（站点访问返 410；保留记录可重新发布）。 |
| `hasn.publish.delete` | `publish:write` | high | 删除站点（软删，撤销同步）。 |
| `hasn.publish.get` |  | low | 取站点详情（可见性 / slug / url / 最新 revision 摘要）。 |
| `hasn.publish.list` |  | low | 列出当前 owner 的全部发布站点（「我发布的」，不含已删）。 |

- scope 词表统一 `domain:action`（冒号）。publish 写类能力键 `publish:write`；读类工具不声明
  `required_scopes`（`publish:read` 在 scopes.py 登记为展示元数据，但读类工具默认无 scope）。
- 维度① 能力授权（allow/ask/deny）统一适用本 App 工具；**出厂全 `allow`**（16-doc D-v3-1），
  owner 可经 `capability_modes` 把 `publish:write` 设 ask/deny override。
- **敏感可见性升级硬闸**与维度①正交：`create`/`set_visibility` 升级到 password/unlisted/public
  时，即使能力被设「总是允许」也强制主人审批（hasn-mcp `enforce_visibility_upgrade_gate`）。
- `risk` 仅 UI 风险提示（D4），不强制确认；`delete` 标 high 仅作展示分级。
